# Mine Hit & Blow

無料で遊べる、ブラウザ完結型の「推論 × マインスイーパー」ゲームです。

## ローカルで起動
`index.html` をブラウザで開くだけです。ビルド、パッケージ管理、APIキー、アカウント登録は不要です。

## GitHub Pages で公開
1. GitHubで新しいリポジトリを作成します。
2. `index.html` をリポジトリのルートへ追加して push します。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、公開するブランチと `/(root)` を指定して保存します。
5. 表示された Pages URL で動作を確認します。

## ゲームモード
- シングルプレイ
- 2人対戦（同一盤面）
- 2人対戦（出題者が爆弾を配置）

## 無料・依存関係
- HTML / CSS / JavaScript の単一ページ構成
- 外部CDN、外部フォント、外部JavaScript、バックエンド、データベースを使用しません
- ビルド工程や有料サービスは不要です
- ゲーム状態を外部へ送信する処理や、広告・分析コードは含めていません

## セキュリティとプライバシー上の注意
この構成はGitHub Pagesのような静的ホスティングに適した、攻撃面の小さい設計です。ただし、**クライアント側だけで完結するゲームに、対戦相手からの秘密情報保護はありません**。同じ端末で遊ぶ場合、ブラウザの開発者ツールやソース確認によって爆弾の位置を調べられる可能性があります。オンライン対戦で秘密の配置を守るには、サーバー側でゲーム状態と判定を管理する必要があります。

公開前に次を確認してください。
- GitHub Pages の HTTPS で公開する
- APIキー、パスワード、秘密情報をリポジトリに入れない
- 公開後に実機・モバイル幅で盤面と操作を確認する
- GitHub Pages のホスティング設定やブラウザのセキュリティ機能を維持する

このアプリはセキュリティ監査済みであることを保証するものではありません。静的サイトとしての基本的なリスク低減を目的としています。
